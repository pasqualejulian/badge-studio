# Assets y publicación

`public/escudo.svg` y `public/illustrations.svg` son assets de ejemplo aportados durante la POC. El segundo tiene etiquetas de grupo añadidas para separar cornetas, contornos, destellos y estrellas. Las marcas y diseños de ejemplo no deben interpretarse como una licencia de uso de terceros.

La copia pública excluye credenciales, archivos de entorno, identificadores del sitio alojado, historial privado de trabajo, renders temporales, dependencias instaladas y cachés. Incluye sólo el proyecto web y documentación. La configuración pública de hosting contiene bindings vacíos, sin un proyecto asociado.

No se incluyeron las capturas de referencia ni los archivos Blender de trabajo. Los diseños que una persona carga al usar la app no se incorporan automáticamente al repositorio.
